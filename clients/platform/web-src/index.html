What this version can do

      
iPhone and Android cannot inspect every installed app or process like a desktop endpoint-security product. MalGuard therefore scans only files you explicitly choose. The macOS wrapper uses the same isolated local scanner in this first release. Unsupported protection features stay visibly disabled instead of pretending to work.
