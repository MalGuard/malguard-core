MalGuard Public Beta
Desktop version: 0.6.1-beta.1
Core baseline: 0.9.0-rc.1
Date: 2026-09-17

Release status:
- PUBLIC BETA, not Stable/GA.
- Intended for public testing and bug reporting.
- Standard scanning and the installable sealed Windows scanner are included.
- Plus/Pro Sandbox paths remain fail-closed unless the local Windows host successfully self-certifies Windows Sandbox isolation.
- No claim is made that Windows Sandbox has been live-certified on every tester host.

Security posture:
- Runtime package self-integrity is enforced for sealed builds.
- Release/update trust uses signed metadata and package integrity verification.
- CI workflows use pinned external actions and restricted credentials.
- Untrusted samples must never execute directly on the host when Sandbox acceptance is unavailable.

Public Beta acceptance policy:
- A failed or unavailable isolation capability must produce a blocked/inconclusive result, never a false SAFE verdict.
- Security defects reported by beta testers are treated as release blockers for Stable.
- Stable release remains gated on real Windows Sandbox host acceptance evidence and regression validation.
